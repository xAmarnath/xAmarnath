# Profile artwork

The header, project cards, and technology cloud share a warm paper / charcoal palette. The header and cloud have separate mobile compositions; all artwork has light and dark variants.

The cloud uses [Simple Icons](https://github.com/simple-icons/simple-icons) vector paths (CC0). Its 181 projection samples were recorded from [React Icon Cloud](https://github.com/teaguestockwell/react-icon-cloud) / TagCanvas, then exported as a seamless 32-second SVG animation. The SVG contains no JavaScript or external assets. Viewers with `prefers-reduced-motion: reduce` see a still cloud.

Project descriptions are deliberately static. Public activity and language statistics in the profile README come from GitHub Readme Stats.

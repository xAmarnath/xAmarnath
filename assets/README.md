# Profile assets

The transparent, brand-colored cloud uses [Simple Icons](https://github.com/simple-icons/simple-icons) vector paths (CC0). Its 181 projection samples were recorded from [React Icon Cloud](https://github.com/teaguestockwell/react-icon-cloud) / TagCanvas, then exported as a seamless 32-second SVG animation. The SVG contains no JavaScript or external assets. Viewers who prefer reduced motion see a still cloud. The dark variant lightens black icons for contrast.

Repository pin cards, public activity and language statistics use [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats), served by the existing deployment linked in the README. Cards fetch public repository metadata. Social and tool badges use [Shields.io](https://shields.io/); the profile view counter uses [Komarev](https://github.com/antonkomarev/github-profile-views-counter). The counter measures image views, not unique visitors.

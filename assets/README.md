# Profile assets

The transparent, brand-colored cloud uses [Simple Icons](https://github.com/simple-icons/simple-icons) vector paths (CC0). Its 181 projection samples were recorded from [React Icon Cloud](https://github.com/teaguestockwell/react-icon-cloud) / TagCanvas, then exported as a seamless 32-second SVG animation. The SVG contains no JavaScript or external assets. Viewers who prefer reduced motion see a still cloud. The dark variant lightens black icons for contrast.

Repository pin cards, public activity and language statistics use [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats), served by the existing deployment linked in the README. Cards fetch public repository metadata. Social and tool badges use the rounded `flat` style from [Shields.io](https://shields.io/). The live profile view counter uses [Moe-Counter](https://github.com/journey-ad/Moe-Counter) with its Miku theme. Theme artwork is provided by the counter service and is excluded from its code license. The counter measures image requests, not unique visitors; GitHub image caching can affect the count.
